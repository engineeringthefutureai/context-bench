Every run, as the model saw it

Runs can be browsed as a table or as a matrix of tasks against harness levels. Opening one shows its prompt split into parts, the model's thinking, its answer or tool transcript, the patch and the test output, and a second run can be opened alongside it for comparison.

Token counts per part are estimated from character length. The server reports the per-run totals (in, out). The harness sends L7's tool schemas with the request, and they aren't shown as text. Local file paths are removed from test output.

Source and data: github.com/engineeringthefutureai/context-bench
