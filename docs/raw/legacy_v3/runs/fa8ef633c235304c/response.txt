The request is clear: `Product` should expose a `url_path` built from its title using the existing title-slug rule (`slug_for_title` in `shopkit/utils/text.py`), returned as `"/products/<slug>"`. It's read-only, so a `@property` on the dataclass (no new field, no default — the dataclass stays plain).

I verified the dependency direction is safe: `shopkit/utils/text.py` imports only `re` and `unicodedata`, so adding it to `shopkit/catalog/models.py` introduces no circular import (the rest of the codebase, e.g. `categories.py` and `variants.py`, already imports `slug_for_title`/`normalize_sku` into catalog modules).

from dataclasses import dataclass

from shopkit.utils.text import slug_for_title


@dataclass
class Product:
    sku: str
    title: str
    price_cents: int
    active: bool = True

    def is_purchasable(self) -> bool:
        return self.active and self.price_cents > 0

    @property
    def url_path(self) -> str:
        """Stable storefront address for the product page, e.g. "/products/blue-mug"."""
        return f"/products/{slug_for_title(self.title)}"
