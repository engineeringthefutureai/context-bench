The request is clear: add a `reserve` method to the `Stock` class that decrements the on-hand quantity for a given SKU, and raises a `Conflict` error (from `shopkit.errors`) if there isn't enough stock, including `requested` and `available` quantities in the error details.

Looking at the codebase:
- `shopkit/errors.py` defines `Conflict(ShopError)` with `http_status = 409`.
- `ShopError.__init__` takes a message and `**details` kwargs, stored in `self.details`.
- Other services like `OrderBook` raise errors in this pattern: `raise DuplicateOrder(f"...", order_id=order.id)`.

So I need to:
1. Import `Conflict` from `shopkit.errors`
2. Add a `reserve` method that checks if available quantity is sufficient, and if not, raises `Conflict` with appropriate message and `requested`/`available` kwargs. If sufficient, decrement the on-hand quantity.

```python
from shopkit.errors import Conflict


class Stock:
    """On-hand quantities per SKU."""

    def __init__(self):
        self._on_hand: dict[str, int] = {}

    def receive(self, sku: str, qty: int) -> None:
        self._on_hand[sku] = self._on_hand.get(sku, 0) + qty

    def available(self, sku: str) -> int:
        return self._on_hand.get(sku, 0)

    def reserve(self, sku: str, qty: int) -> None:
        current = self._on_hand.get(sku, 0)
        if qty > current:
            raise Conflict(
                f"insufficient stock for {sku}",
                requested=qty,
                available=current,
            )
        self._on_hand[sku] = current - qty
```
