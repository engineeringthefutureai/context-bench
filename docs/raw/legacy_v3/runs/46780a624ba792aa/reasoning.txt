def add_line(self, sku: str, qty: int, unit_cents: int) -> OrderLine:
    """Add a line, merging into an existing line with the same SKU and unit price."""
    for line in self.lines:
        if line.sku == sku and line.unit_cents == unit_cents:
            line.qty += qty
            return line
    line = OrderLine(sku=sku, qty=qty, unit_cents=unit_cents)
    self.lines.append(line)
    return line
```

def add_line(self, sku: str, qty: int, unit_cents: int) -> OrderLine:
    """Add a product to this order.

    If the order already contains a line for the same SKU at the same unit price,
    that line's quantity is increased instead of adding a duplicate line.
    Returns the line that was added or modified.
    """
    for line in self.lines:
        if line.sku == sku and line.unit_cents == unit_cents:
            line.qty += qty
            return line
    line = OrderLine(sku=sku, qty=qty, unit_cents=unit_cents)
    self.lines.append(line)
    return line
```

Edge cases:
- Empty order → append and return the new line. ✓
- Same SKU but different unit price → append a new line (since prices differ, the rows are considered distinct). ✓
- qty could be 0 or negative — the request doesn't call for validation, and the codebase's models don't perform validation either. I'll keep it simple and not add validation beyond what the request implies. Since the task specifies "increment that line's quantity," just increment it as-is.
