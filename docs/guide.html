Guide

Run it yourself

The harness needs Python and an OpenAI-compatible chat endpoint. Self-hosting is optional.

What you need

ComponentNeeded?What it's for
Python 3.11+YesThe harness, the fixture repository and the tests. Standard library plus a few packages.
Chat endpointYesAny OpenAI-compatible /v1/chat/completions API with tool calling (for L7). A hosted API works.
Embeddings endpointOptionalAny /v1/embeddings API, for the embedding retriever (L4/L5 embed, L7 hybrid). Without it those variants are skipped and BM25 still runs.
Cache controlOptionalClean mode needs a vLLM server with VLLM_SERVER_DEV_MODE=1 (prefix-cache reset) or a restart command. On a hosted API you can't control caching, so runs may share cached prefixes. This changes latency and cached-token counts, not the answers' correctness.
JudgeOptionalA coding-agent CLI for blind grading (agy or Claude Code), confined to read-only tools.

Steps

git clone https://github.com/engineeringthefutureai/context-bench
cd context-bench
pip install -e '.[dev]' && pytest             # checks every task's contract too

cp .env.example .env                           # endpoint URL and API key
$EDITOR config/experiment.toml                 # [models], [embedder], [grading]

cbench validate-retrieval --retrievers bm25,embed
cbench one --task reuse-001 --level L1         # a single run
cbench run --model <key>                       # the full sweep, resumable
cbench run --model <key> --clean --thinking    # final-round mode: serial, cold cache
cbench rescore                                 # recompute derived fields, no model calls
cbench grade                                   # blind judge per task
cbench report

Adding a task

Each task is tasks/<id>/task.toml plus hidden_tests/ and solutions/. The unmodified repository must fail the hidden tests and reference.diff must pass them and keep the repository's own tests green. Tasks that depend on repository context also keep a plausible context_blind.diff that fails. tests/test_tasks_verified.py checks all of it.
