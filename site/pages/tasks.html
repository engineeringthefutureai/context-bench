Categories and tiers

Reuse
The change needs a helper that already exists in the project. A hidden reuse test checks that the new code calls it. Tier 3: the helper's name matches the task's wording. Tier 4: it doesn't, or several helpers are needed.
Convention
Tier 5. The project has a way of doing this (raising domain errors, publishing events, reading settings) that is defined in other files.
Cross-file
Tier 6. A feature that needs coordinated edits in several files: model, fulfillment and API serializer.
Control
Tiers 1-2. Everything needed is in the task or the target file. A baseline for what the model does without repository context.
Trap
The helper's signature and docstring promise something its body no longer does. Correct means reusing it and fixing it.
