Raw data

Every run, as it was seen by the model

The runs can be browsed as a table, or as a matrix of tasks against harness levels. When a run is opened, its prompt is shown split into parts, along with the model's thinking, its answer or tool transcript, the patch and the test output. A second run can be opened for a side-by-side comparison.

Token counts per part are estimated from character length. The per-run totals (in, out) are reported by the server. L7's tool schemas are sent with the request and aren't shown as text. Local file paths are removed from test output.
